# 🚀 Nexus Blueprint: Solo Dev Environment

This repository automates the setup of my GitHub Codespaces, optimized for a 
solo developer working from an i686 laptop with 2GB RAM.

## 🛠️ Commands & Shortcuts
| Command | Location | What it does |
| :--- | :--- | :--- |
| `switchspace [n]` | Laptop | Stops VM, swaps to [n] cores, and connects via SSH. |
| `mkproj [name]` | Cloud | Creates a new folder with main.py, README, and .venv. |
| `pyenv` | Cloud | Fast-tracks virtual env setup and creates a .gitignore. |
| `quota` | Cloud | Checks remaining core-hours before the monthly reset. |
| `maskcard` | Cloud | Securely masks Aadhaar numbers to last 4 digits. |
